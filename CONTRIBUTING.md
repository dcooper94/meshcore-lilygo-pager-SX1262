# Contributing

This is a personal firmware fork for the LilyGo T-LoRa Pager (SX1262). It is not a general-purpose library.

**To report a bug or suggest a feature** — open a GitHub issue. Describe the hardware behaviour you're seeing and the firmware version you're running.

**To submit a change** — open an issue first to discuss, then follow the development workflow in [`AGENTS.md`](AGENTS.md).
